# as2-deob — расшифровщик обфусцированного AS2 (AVM1)

Снимает обфускацию вида «плоский автомат состояний», которой закрыты 945a (FLV-плеер Moyea)
и rga (Rage Truck, box10):

- каждый блок кода — `while(true)` по переменной `"\x01"`, стартовое значение даёт функция `"\x04\x05"`;
- ложные условия через мусорные переменные (`"\x0f" = 1`, `!eval("\x0f")`), мусорные push;
- куски кода спрятаны в байтах других тегов (переходы за пределы блока), пул строк
  переключается по дороге — поэтому декомпиляторы (FFDec) показывают кашу и «битые» имена.

Как работает: частичное выполнение. Скрипт идёт по байткоду от начала блока, считает всё, что
известно заранее (константы и служебные переменные обфускатора), и выбрасывает это; инструкции,
которые работают с настоящими данными игры, переписывает подряд, а настоящие ветвления сохраняет.
На выходе — обычный линейный код с одним пулом строк, записанный в копию SWF.
Обрабатываются кадры (DoAction), #initclip (DoInitAction), onClipEvent (PlaceObject2/3) и кнопки
(DefineButton2). Блок, который разобрать не удалось, остаётся как был (скрипт об этом пишет).

Запуск (нужен только Python 3):

    python deob.py игра.swf игра_clean.swf
    python deob.py игра.swf игра_clean.swf -v    (подробно по блокам)

Результат открывается в FFDec как нормальный AS2 (классы с настоящими именами методов и полей)
и работает так же, как оригинал (проверено на 945a и rga в Ruffle и в нашем AVM1).
Сжатые LZMA-файлы (ZWS) не поддерживаются; обычные (FWS/CWS) — да, на выходе несжатый FWS.
